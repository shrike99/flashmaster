# 🚀 Quick Start Guide

Get FlashMaster running in 3 minutes!

---

## 🌐 Option 1: Use Online (Easiest)

Just visit the live demo (once deployed):
```
https://yourusername.github.io/flashmaster/
```

All data is stored in your browser. No account needed!

---

## 💻 Option 2: Run Locally

### Prerequisites
- Node.js 18+ ([Download here](https://nodejs.org/))

### Steps

1. **Clone or download this repository**
   ```bash
   git clone https://github.com/yourusername/flashmaster.git
   cd flashmaster
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   - Navigate to: `http://localhost:5173`
   - Start creating flashcards! 🎉

---

## 📚 First Steps

1. **Add your first card**
   - Click "Add Cards" in the sidebar
   - Enter a question and answer
   - Try pasting an image (Ctrl+V)
   - Click "Save All Cards"

2. **Study your cards**
   - Go to "My Cards"
   - Click "Study All"
   - Flip cards with Space or click
   - Mark answers with ←/→ or drag

3. **Track your progress**
   - Visit "Statistics"
   - See your accuracy and study history

---

## 🎯 Pro Tips

- **Use Markdown**: Format with `**bold**`, `*italic*`, `` `code` ``
- **Keyboard shortcuts**: Space, ←, →, 1, 2
- **Paste images**: Copy any image, paste into a card
- **Export regularly**: Backup your cards as JSON
- **Dark mode**: Toggle at bottom of sidebar
